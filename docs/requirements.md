# V1.0 需求与验收映射

目标用户：需要核对运营导出与经营汇总的分析师；价值是可复算地定位差异及拒绝不可比比较，不承诺节省时间的未测指标。

|需求|模块|验收|
|---|---|---|
|双 CSV/XLSX、ID 保真、受控读取|loader|空文件、坏表头、Excel、资源限制|
|定义/单位/币种/日期/范围/截止确认|contract|缺确认、口径、时间、单位阻断|
|五态对齐决策|alignment|exact、aggregate、total、confirmation、blocked|
|唯一键/空键/重复/多对多|normalization、matching|拒绝膨胀，不删除记录|
|多加总指标、Decimal、容差|comparison|边界、抵消、交换/排列/拆分性质|
|独立运行、血缘、HTML、错误工件|evidence、CLI|三 Demo、文件哈希、退出码|
|原框架增量集成|method reference|原回归、真实四角色验证|

支持两来源、显式字段映射、精确或合法向上聚合及经确认共同总量；不支持隐式口径转换、汇率、比率、去重人数、MRR、模糊匹配、自动修复或生产同步。来源一致性、可比性、正确性、根因四者独立。
